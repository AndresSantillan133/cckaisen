# CCKaisen

Landing page de fitness coaching para **CCKaisen**, con el coach **Charly** en Uruapan, Michoacán.

## Stack

- React 18 + Vite + TypeScript
- Tailwind CSS v4
- GSAP + Framer Motion

## Secciones

1. Loading screen (contador 0-100 + palabras rotativas)
2. Hero con navbar flotante y CTA a WhatsApp
3. Servicios (Planes, Nutrición, Mentoría)
4. Transformaciones (galería bento)
5. Stats animados
6. Testimonios con ratings
7. Contacto (marquee + footer + botón flotante de WhatsApp)

## Desarrollo

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
